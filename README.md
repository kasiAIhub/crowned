# Crowned

A mobile-first live queue app for a braiding salon. Parents book a place from anywhere and get told when to come, so nobody waits in the chair area all day. The salon floor screen tracks real chair progress and moves every estimate as work goes on.

## What it does

- Four-step parent booking and "find my booking" with live status
- Salon console: PIN-protected floor view, chair progress, settings
- WhatsApp call-backs via Twilio when it is her turn (sandbox in the demo)
- Practice salon demo with simulated data

## Stack

TanStack Start, React, TypeScript, Tailwind, Supabase with PIN hardening and lockout, Lovable.

## Running locally

npm install, copy .env.example to .env and fill your own values, then npm run dev.
